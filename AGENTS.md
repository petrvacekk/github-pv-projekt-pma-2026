
# Ownly – PMA Semestrální projekt

## O projektu
Ownly je Android aplikace pro evidenci a organizaci osobních věcí, primárně oblečení.

Uživatel bude moci:
- Vytvářet a spravovat vlastní kategorie.
- Přidávat oblečení s fotografiemi, názvem, popisem a cenou.
- Zobrazovat, upravovat a mazat uložené položky.
- Vyhledávat a filtrovat oblečení.
- Vytvářet a ukládat kombinace oblečení (outfity).
- Postupně rozšířit evidenci také na další osobní věci.

Automatický import produktů z URL není součástí základního rozsahu.

## Požadavky vyučujícího
- Android aplikace střední obtížnosti.
- Povinné použití databáze.
- Minimálně CRUD operace nad databází.
- Originální GitHub Wiki tutoriál.
- Student musí umět aplikaci vysvětlit u zkoušky.

## Technologie
- Kotlin
- XML layouty (ne Jetpack Compose)
- Android Fragments
- ViewBinding
- Room pro lokální databázi
- Gradle
- Git a GitHub

Vývoj probíhá primárně ve VS Code.
Android Studio slouží ke správě SDK, emulátoru a případnému ladění.

## Zásadní pravidla vývoje
1. Používej především metody a postupy z repozitáře vyučujícího.
2. Před implementací nového tématu zkontroluj odpovídající výukový materiál, pokud je dostupný.
3. Piš jednoduchý, přehledný a srozumitelný kód.
4. Nezaváděj zbytečné knihovny ani složitou architekturu.
5. Postupuj po malých, logických krocích.
6. Každou důležitou část kódu musí student dokázat vysvětlit.
7. Vysvětluj česky, používej správné technické názvy.
8. Zachovávej funkčnost již dokončených částí aplikace.
9. Nevytvářej zbytečné soubory ani rozsáhlé abstrakce.
10. Před větší úpravou nejprve vysvětli navržené řešení.
11. Po změnách shrň, které soubory se upravily a proč.
12. Git commity a push prováděj pouze na výslovný pokyn.

## Vývojový postup
1. Zprovoznění základního Android projektu.
2. Návrh jednoduché navigace pomocí fragmentů.
3. Kategorie a přehled oblečení.
4. Databáze Room a CRUD operace.
5. Přidávání a zobrazování fotografií.
6. Vytváření a ukládání outfitů.
7. Vyhledávání a filtrování.
8. Testování, dokumentace a GitHub Wiki.

Cílem není pouze dokončit aplikaci, ale porozumět její implementaci a být schopný ji samostatně obhájit u zkoušky.
